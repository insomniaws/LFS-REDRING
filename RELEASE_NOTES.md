# Red Ring — v1

Автор карты: **HighSpeedGarage**.
Конвертация: Assetto Corsa → BeamNG.drive → Live for Speed.

Ночное освещение, оптимизированный ландшафт, деревья вокруг трассы, исправленные покрышки и две гаражные позиции для парного дрифта.

**Установка:** папку `red_ring` из архива поместить в `LFS/mods/tracks/` при закрытой игре.
Требуется LFS S3 и совместимый lfs-custom-track. Другие карты не заменяются.

Прикрепляемый файл: `red_ring.zip`.
