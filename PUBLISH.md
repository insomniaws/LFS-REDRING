# Обновление релиза

Репозиторий: insomniaws/LFS-REDRING. Основная ветка: main.
Первый релиз: v1. Файл для каталога: red_ring.zip, папка red_ring в корне архива.

При обновлении:
1. Сохраните постоянный id D3A2DB в track.ini.
2. Увеличьте version в track.txt и настройках сборщика.
3. Соберите и проверьте карту, обновите size, date, README и CHANGELOG.
4. Создайте новый тег v2 (затем v3 и т. д.) и прикрепите обновлённый red_ring.zip.
5. Проверьте загрузку через Get mods.

release_assets исключена из Git. Архивы прикрепляются к Releases.
GitHub допускает правки документов без пересборки карты; изменение содержимого игрового архива требует новой версии.
